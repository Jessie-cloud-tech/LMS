## Head of Department (HoD) User Manual

Purpose: The HoD reviews and moderates marks before their official release.

Main activities:
1. Login
   - Enter HoD credentials.
   - Access the HoD menu.
2. Review marks
   - Select the relevant department or course.
   - View submitted and marked assignments.
   - Review the lecturer's awarded marks and feedback.
3. Moderate marks
   - Select a mark that requires moderation.
   - Review the existing mark.
   - Make an authorised adjustment where necessary.
   - Record the reason for the adjustment.
4. Approve and release marks
   - Review the final marks.
   - Approve the results.
   - Release the approved marks to students.
5. Logout
   - Exit the HoD menu.
