## Lecturer User Manual

Purpose: Lecturers manage assignments, student submissions, extensions and marking.

Main activities:
1. Login
   - Enter lecturer credentials.
   - Access the lecturer menu.
2. Create assignments
   - Select the relevant course.
   - Enter the assignment title and description.
   - Enter the submission deadline.
   - Enter the maximum mark.
   - Save the assignment.
3. Grant extensions
   - Select the relevant assignment.
   - Select the student who requires an extension.
   - Enter the new deadline and reason.
   - Save the extension.
4. View submissions
   - Select an assignment.
   - View submitted student work.
   - Identify submission status.
5. Mark submissions
   - Open the relevant submission.
   - Enter the awarded mark.
   - Provide written feedback.
   - Save the marking decision.
6. Logout
   - Exit the lecturer menu after completing the required activities.
