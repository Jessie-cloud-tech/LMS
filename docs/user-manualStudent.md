## Student User Manual

Purpose: Students use the LMS to access course information, submit assignments and view results.

Main activities:
1. Login
   - Enter the student username and password.
   - Access the student menu.
2. View courses
   - Open the course section.
   - View the courses in which the student is enrolled.
3. View assignments
   - Select a course.
   - View available assignments.
   - Check assignment deadlines and submission status.
   - Check whether an extension has been granted.
4. Submit assignments
   - Select the assignment.
   - Upload or submit the required work.
   - Confirm the submission.
   - Check the submission status.
5. Resubmit assignments
   - Open an assignment that permits resubmission.
   - Submit the updated work before the applicable deadline.
6. View marks and feedback
   - Open the grades section.
   - View released marks.
   - Read lecturer feedback.
7. Logout
   - Exit the student menu.
