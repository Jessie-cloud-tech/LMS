## Administrator User Manual

Purpose: The administrator manages the users and academic structure of the LMS.

Main activities:
1. Login
   - Open the LMS.
   - Enter the administrator username and password.
   - Access the administrator menu.
2. Manage user accounts
   - Create user accounts.
   - Enter the required account details.
   - Assign the correct role.
   - Update or manage existing accounts.
3. Manage departments
   - Create departments.
   - View existing departments.
   - Update department information where permitted.
4. Manage courses
   - Create courses.
   - Assign courses to departments.
   - Assign lecturers to courses.
5. Enrol students
   - Select the relevant student.
   - Select the course.
   - Complete the enrolment process.
6. View audit records
   - Access the audit log.
   - Review recorded system activities and relevant changes.
7. Logout
   - Exit the administrator menu.
   - Log out after completing administrative activities.
