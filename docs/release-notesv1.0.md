## Release Notes -Version 1.0

Product: School Learning Management System
Version: v1.0
Release type: Initial release
Technology: C++17 and SQLite

## Overview
Version 1.0 represents the initial release of the School Learning Management System. It provides a centralised system for managing academic activities, assignment submissions, marking and moderation.

## Features included
|Feature	            |Description
|-----------------------|---------------------------------------------------------------------
|User authentication	|Allows users to log in using their credentials
|Role-based access	    |Provides separate functionality for Admin, Lecturer, HoD and Student
|User management	    |Allows administrators to manage accounts
|Department management	|Supports management of academic departments
|Course management	    |Supports course creation and lecturer assignment
|Student enrolment	    |Allows students to be enrolled in courses
|Assignment management	|Allows lecturers to create assignments and deadlines
|Individual extensions	|Allows lecturers to grant extensions to individual students
|Submission management	|Allows students to submit and resubmit assignments
|Late penalties	        |Applies the defined late-submission penalty rules
|Marking and feedback	|Allows lecturers to grade submissions and provide feedback
|Moderation	            |Allows HoDs to review and adjust marks
|Mark release       	|Allows approved marks to be released to students
|Audit logging	        |Records relevant system activities and changes

## Known limitations
- Individual extensions are supported, but class-wide extensions are not yet included.
- The system is designed around the current local deployment arrangement.
- Future improvements may be required based on feedback from school users.
